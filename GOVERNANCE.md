# Governance

- **Working Group**: Technically decisive committee for modeling and approval.
- **AAS Architect**: Monitors structural model consistency and adherence to metamodel specifications.
- **Review by LCA/EPD domain experts**: Ensures technical correctness regarding LCA requirements, ISO 14025, EN 15804.
- **Review by AAS and implementation experts**: Ensures correct technical implementation.
- **Documented handling of comments**: Feedback from reviews is tracked and evaluated in issues.
- **Decision-making for open modeling questions**: Done by consensus in the working group.
- **Handling of breaking changes**: Must be justified and explicitly approved.
- **Separation**: This repository is a Working Draft and not an official IDTA publication.
