# Reviewer Guide

Welcome to the review of the EPD Type III Submodel Template!

1. **Review focus**: Please check structural correctness related to ISO 14025 and the AAS V3.0 metamodel.
2. **Review issues**: Use the GitHub Issue templates for feedback.
3. **Template vs. Instance**: Ensure the generic template does not contain manufacturer-specific instance data. The instance data is strictly found under `examples/wago-00001/`.
4. **Reference files**: In case of discrepancies, compare the WAGO instance with the original PDF in the `source` folder.
