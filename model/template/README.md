# EPD Type III Submodel Template

This directory contains the generic template file (`epd-type-iii-submodel-template.aasx`).

The template defines the structure for the digital representation of an Environmental Product Declaration (EPD) Type III.

## Properties
- **kind**: Template
- **AAS Metamodel Version**: V3.0
- Contains **no** concrete WAGO product values.
- Contains **no** concrete LCIA results as instance data.
- Contains **no** fixed instance-specific `idShort`s (such as `GWP_total` or `A1_A3`).
- Is fully **dynamically instantiable**.
