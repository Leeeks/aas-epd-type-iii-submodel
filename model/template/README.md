# EPD Type III Submodel Template

Dieses Verzeichnis enthält die generische Template-Datei (`epd-type-iii-submodel-template.aasx`).

Das Template definiert die Struktur zur digitalen Repräsentation einer Environmental Product Declaration (EPD) Type III.

## Eigenschaften
- **kind**: Template
- **AAS-Metamodellversion**: V3.0
- Enthält **keine** konkreten WAGO-Produktwerte.
- Enthält **keine** konkreten LCIA-Ergebnisse als Instanzdaten.
- Enthält **keine** festen instanzspezifischen `idShort` (wie `GWP_total` oder `A1_A3`).
- Ist vollständig **dynamisch instanziierbar**.
